# hclient-winhttp

`Transport` over Windows' WinHTTP.

Use it on Windows when you want the system HTTP stack: its proxy
resolution, its certificate handling and its per-machine policy, rather
than a userspace TLS and connection pool.

Part of [hclient](https://github.com/GamePad64/hclient), a cross-platform
HTTP client for native, browser and WASI targets.
